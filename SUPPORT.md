# Support

## Community help

- **Documentation:** https://docs.restowbackup.com, including
  [troubleshooting](https://docs.restowbackup.com/administrators/troubleshooting/).
- **Questions and setup help:** [GitHub Discussions](https://github.com/restow-backup/restow/discussions).
  Answers come from the community and the maintainer when time allows; there
  is no guaranteed response time.
- **Bugs:** open an issue with the bug report template (version, log excerpt
  and storage target are required).
- **Security problems:** privately, as described in [SECURITY.md](SECURITY.md).

## Paid help

Licenses for the Business and Service Provider editions include the software
and its updates, not support. Setup, migration and operation are available
